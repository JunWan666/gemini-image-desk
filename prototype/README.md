# Local Prototype

Open `index.html` directly in a browser to review the current Gemini Image Desk UI direction.

## What It Covers

- Default Chinese UI with English i18n switch
- Desktop three-column workbench
- Mobile responsive layout
- Prompt editor, reference images, result canvas, output settings, history
- Empty, running, and error states

## Notes

This prototype is a design artifact, not the production app. It avoids Gemini API calls and only demonstrates layout, copy, interaction states, and visual direction.
