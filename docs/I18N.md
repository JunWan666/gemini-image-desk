# i18n Rules

## Supported Locales

- Default: `zh-CN`
- Secondary: `en-US`

## Product Copy Direction

中文是主使用语言，文案应自然、短、工具化。英文文案作为第二语言，不能只用机器直译，要保留产品语气。

## Implementation Rules

- 不在 React 组件中硬编码用户可见文案。
- 所有按钮、表单标签、空状态、错误提示、历史记录字段名都走字典。
- 模型 id、Base URL、API Key 这类技术名词不翻译。
- 默认语言为 `zh-CN`。
- 第一版允许手动语言切换，不要求自动识别系统语言。

## Suggested Structure

```text
lib/
  i18n/
    locales/
      zh-CN.ts
      en-US.ts
    keys.ts
    use-i18n.ts
```
